# Project Overview: The Atelier (Backend)

## 1. Introduction
The Atelier là một dự án E-commerce thời trang cao cấp. Backend được thiết kế theo hướng module hóa, dễ mở rộng và bảo trì.

## 2. Tech Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MySQL (TiDB Cloud)
- **ORM**: Sequelize
- **Storage**: Cloudinary (Image management)
- **Testing**: Jest & Supertest

## 3. Key Features (Current)
- Hệ thống Catalog (Products, Categories, Collections).
- Quản lý ảnh thông qua Cloudinary.
- Centralized Error Handling.
- Tách biệt logic nghiệp vụ (Service Layer).
- Bộ Unit Test toàn diện cho API.

## 4. Current Phase
- **Phase 1: Catalog & Display** (Completed).
- **Next Phase: Authentication & User Management**.
